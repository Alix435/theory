### Канальный + Физический
- **Физический:** Сам кабель, свет в оптоволокне, радиоволны Wi-Fi.
- **Канальный:** Доставка внутри **одной локальной сети** по **MAC-адресу** (уникальный «железный» адрес сетевой карты).
### Сетевой
- Работает с **IP-адресами** (`192.168.1.100`).
- Маршрутизаторы (роутеры) смотрят на IP и решают, куда дальше переслать пакет.
### Транспортный
- Работает с **портами** (числа 1–65535).
- Выбирает режим доставки:
    - **TCP** — надёжно (с подтверждением доставки). Для сайтов, почты, файлов.
    - **UDP** — быстро (без подтверждений). Для видео, звонков, игр.
### Прикладной
- Это сами **протоколы приложений**: `HTTP` (веб), `SMTP` (почта), `RDP` (удаленный стол), `DNS` (имена).
