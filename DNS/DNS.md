

Учите:
- Типы записей: A, AAAA, CNAME, MX, TXT, NS, PTR
- Как работает рекурсия и кэширование
- Зоны (forward/reverse)
- Инструменты: nslookup, dig, whois

Практика:
- Поднимите свой DNS-сервер (Bind9 на Linux или DNS на Windows Server)
- Создайте зону company.local
- Настройте записи: web → 192.168.1.10, mail → 192.168.1.20
